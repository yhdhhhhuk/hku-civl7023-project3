# C第二阶段本地入口

先按本ZIP对齐Git固定基线，再导入。当前公共主程序仍默认legacy70g，第二阶段必须显式A-candidate与telemetry。
从新克隆根目录使用`第二阶段入口.py calibrate`、`single`、`full`，包装器强制候选与全程采集、录像；同名输出拒绝覆盖。
默认输出在`运行验证/C_第二阶段复现/`，C需先单件再全16件。新启动器为`启动第二阶段候选装配`，旧`启动C装配演示`不是本阶段入口。
