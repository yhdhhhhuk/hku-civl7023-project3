## 复现与生成脚本

在仓库根目录使用已有项目环境即可重新生成本目录的参数包、误差分解图及 `.pptx` 幻灯片（不改动任何第三阶段封存文件）：

```bash
P3_PY=05_Project3_月面机器人装配/.venv/bin/python
"$P3_PY" 第三阶段入口.py verify
"$P3_PY" 05_Project3_月面机器人装配/B_第四阶段定稿与汇报/verify_stage4.py
"$P3_PY" 05_Project3_月面机器人装配/B_第四阶段定稿与汇报/build_b_slides_pptx.py --preview
```

`--preview` 使用 PATH 上的 `soffice` 和 `pdftoppm` 从实际 PPTX 渲染五页总览。只生成 PPTX 时可省略该选项。
