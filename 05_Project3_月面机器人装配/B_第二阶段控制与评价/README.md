# B第二阶段：候选载荷、全程记录与评价

第二阶段候选参数、完整记录及基本力矩已通过本地验收；材料仍待A认可。
运行请从新克隆根目录使用`第二阶段入口.py`：先calibrate，再single，再full；分析必须显式给--input和本机--calibration。无参数evaluate.py仅做96目标检查，不分析新运行。安装／角色任务见ZIP给A和给C说明。

## 参数及坐标

来源为`A_结构设计与CAD/04_构件参数与文献/质量惯量_候选参数.json`及`材料来源与假设.md`。密度2500kg/m³；体积2.9042666667×10⁻⁵m³；质量0.07260666666666667kg。底面中心为几何原点，质心为[0,0,0.010566253098888994]m。质心惯量（kg·m²）为diag(7.554717961655561e-6,1.8706254628322218e-5,2.040344e-5)。旧值为70g、COM_Z11mm和50×30×25mm包络惯量。

读取完整张量后检查正定性及非对角项；当前轴即主轴，URDF惯性朝向为单位四元数。若将来非对角项非零，程序明确拒绝，须先实现主轴转换，不能静默抹掉非对角项。没有用底面原点惯量替代质心惯量，也不需再次平行轴平移。

Bullet的base pose为质心／惯性系，几何底面原点恢复为`p_origin=p_base-R_base*COM`。本模型惯性朝向为单位旋转，故几何朝向与base朝向相同。初始布置、实际接触槽判断、持件影子模型、辅助约束相对位姿及最终误差均复用同一COM；约束是基于实际COM姿态创建，未直接把质心当底面原点。`loaded_payload.json`核对实际加载质量、惯量、惯性原点、朝向和16件几何原点重建。

## 日志字段与反馈含义

`telemetry.py`在每个外部物理步之后调用一次，不依赖60Hz控制器是否运动。`joint_full_trace.csv`：

- `step,time_s,item,phase,attached`：外部步号、仿真时间、当前处理件号、装配阶段和辅助抓持状态。放置后1秒等待仍标记release，随后settle及final_settle独立标记。
- `q1..q6_rad,dq1..dq6_rad_s`：六转动关节状态；`q7..q8_m,dq7..dq8_m_s`为夹爪直线关节。
- `motor1..motor6_Nm`、`motor7..motor8_N`：`getJointStates`元组第4项原始值（索引3），POSITION_CONTROL约束电机反馈。未混入关节反力或辅助约束载荷。
- `reaction{j}_Fx_N..Mz_Nm`：启用传感器后的元组第3项六分量API原始反力反馈。保持Bullet的传感器坐标约定，未转换为世界系、不用于驱动力矩峰值统计。
- `constraint_Fx_N..Mz_Nm`：辅助固定约束API原始反馈；未抓持时填零，用attached判别。它不是六轴电机力矩，也未与电机力矩相加；未独立标定其子步换算或参考系，不用于承载认证。

`trajectory.csv`为20Hz当前构件几何原点、朝向、TCP、接触及开口；`inventory_trace.csv`为2Hz全部16件的base COM位姿；`b_control_trace.csv`是60Hz运动阶段的B控制误差与命令。三者频率与用途不同，不把运动控制日志当成全程采集。动作切换时旧目标误差会跳变，需与每次运动的最终收敛误差分开。

## 4子步下的关键校准

本机PyBullet3.2.7外部240Hz、4子步时，motor原始值是最后子步电机冲量除以外部dt。由静态重力平衡（理论0.162N·m）和无重力饱和加速度实验独立验证：1子步原值=实际等效值；4子步原值乘4恢复最后子步的等效电机力矩／夹爪力。`反馈字段独立核对.json`保留6组实验。不是将四个子步取平均，也没有记录每个960Hz峰值。

因此报告给出**原始反馈峰值**和**最后子步等效力矩=4×原始反馈**；RMS指240Hz等间隔样本上最后子步等效值的均方根。电机force参数按外部dt转冲量，本机饱和实验同样测出4倍子步等效上限：六轴URDF/命令100对应约400N·m子步等效上限，闭爪命令1N对应约4N的子步等效上限，开爪命令1/3N对应约4/12N。这里保留既有命令及4子步设置，不把历史“1N”描述误读为已经标定的真实接触力。实际接触正压力仍见接触数据。

这些都是本机模型与求解器的数值限幅，不能作为厂家安全额定值。切换Bullet版本、时间步、子步数或控制模式必须重做此校准。官方实现的电机冲量／外部时间步关系与本机测试一致，见[Bullet服务端源码](https://github.com/bulletphysics/bullet3/blob/master/examples/SharedMemory/PhysicsServerCommandProcessor.cpp)的`processRequestActualStateCommand`及电机命令处理；线上master仅作机制核对，本机独立实验是本次数值结论依据。

## 运动学与碰撞评价边界

几何TCP雅可比为世界系6×6、[线速度;角速度]，评价采用W=diag(1/0.3,1/0.3,1/0.3,1,1,1)。给出最小奇异值与条件数，不设未经依据的通用奇异性合格线。名义96目标独立求解；实际执行目标另存表；240Hz实际关节样本检查限位和缩放奇异值，60个状态用中心差分独立核对雅可比，约128个控制样本独立FK核对TCP。

保持原释放门控、缓存参数1e-5、240Hz/4子步、自碰撞排除表、接触槽条件、碰撞阈值和已装构件检查。离散规划／命令／物理接触检查通过不等于对所有连续时间有数学保证。辅助固定约束maxForce30的抓取仍是简化抓持，不是纯摩擦抓取。没有材料强度、硬件热／电机安全或抗倾覆认证。
