## 单独复现

复制整个 `simulation` 目录，在该目录里打开终端。Windows 建议复制到全英文路径，例如 `C:\p3\simulation`，并将新运行输出保存在该路径下。采用 Python 3.12，可先仅用标准库核对两组正式实验的文件与无损日志。

```sh
python 第三阶段入口.py verify
```

在已激活的 Python 3.12 虚拟环境中安装依赖，随后可以核对第四阶段数据或重新运行。第四阶段复核脚本会在当前副本重新生成参数文件、误差表和图表。建议在副本中执行。

```sh
python -m pip install -r 05_Project3_月面机器人装配/requirements.txt
python 05_Project3_月面机器人装配/B_第四阶段定稿与汇报/verify_stage4.py
python 第三阶段入口.py calibrate
python 第三阶段入口.py single
```

用 `python 第三阶段入口.py full` 运行推荐的 16 件工况，加 `--gui` 可观察装配。默认开启抓取偏置补偿，独立新结果写入 `runs/local/`。需要逐行分析第三阶段记录时，执行 `python 第三阶段入口.py restore` 还原 10 份 CSV。仿真使用候选构件质量 72.61 g 和接触门控辅助抓持。力矩是校准后的最后子步等效值。
